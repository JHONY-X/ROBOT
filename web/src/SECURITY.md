# Security Architecture & Compliance

> Implementation status: this document records requirements and known limitations for a prototype. It is not a certification or claim of production security or legal compliance.

## 1. Role-Based Access Control (RBAC)
- **Frontend:** `src/proxy.ts` checks role and session cookies to guide navigation. These client-presented cookies are not a trusted authentication mechanism and do not provide production authorization.
- **Backend:** Not implemented in this project. A backend MUST validate the session on EVERY API request. Hiding UI buttons is NOT security.

## 2. Authentication
- A production authentication provider and trusted session issuer are not implemented.
- Sessions MUST be stored in **HttpOnly, Secure, SameSite=Strict Cookies**. 
- **DO NOT** store JWT tokens or passwords in `localStorage` or `sessionStorage`.
- Admin accounts MUST have Multi-Factor Authentication (MFA) enabled.

## 3. Data Encryption
- **In Transit:** Enforced via HTTPS (TLS 1.3).
- **At Rest:** The database MUST be encrypted at rest (e.g., AES-256). Document storage (AWS S3/Azure Blob) must use server-side encryption.

## 4. Document Security
- Uploaded documents (Licenses, IDs) MUST be stored in a private bucket.
- Access is granted via short-lived, signed URLs generated by the backend after verifying the user's role.

## 5. Audit Logging
- All sensitive actions (Approvals, Refunds, Flag Clearing, Confidential Feedback viewing) MUST be logged with:
  - User ID, Timestamp, IP Address, Action Type, and Reason.
- The `adminService` and `feedbackService` in this frontend are designed to support this audit trail.

## 6. Payment Security (PCI DSS)
- The frontend MUST NEVER handle raw card numbers. 
- Payment MUST be processed via a hosted checkout page (e.g., Chapa, Stripe) approved by Rohobot.

## 7. Compliance
- Compliance with the **Ethiopian Personal Data Protection Proclamation** has not been assessed or certified.
- Retention and incident-response policies require approval and implementation before launch.
- Obtain legal review of the final privacy notice, consent, retention, and breach-notification procedures.
